## 关键技术点（对照 Fast-DDS 3.6 源码 + 官方 static_edp_discovery 示例）

- 静态发现 = SIMPLE PDP（参与者发现保持默认多播）+ **STATIC EDP**（端点发现走 `<staticdiscovery>` XML + ESR/ESW 位图属性经 PDP 交换）
- XML `<participant name="X">` 的 name 必须等于实际参与者名（`get_reader_from_position` 按名定位）
- 端点 `entityID`/`userId` 须与 XML 一致（`RTPSEndpointQos::entity_id`/`user_defined_id`）；entityID 解析为 24bit + kind 字节，小值直接映射
- v2 交换格式默认，端点创建后 FastDDS 自动维护位图属性 → 对端按 XML 位置解析端点 GUID
